# Manifiesto fundacional

## Qué sostiene el marco

El repositorio no se fundamenta en un orden externo compartido por conciencias
separadas. Se **auto-constituye** en el punto fijo de su especificación
(`data/iom_spec.json` + predicados Lean). Anotadores, dominios y métricas de
recuperación de reglas son **encuentro**, no fundamento.

## Separación de roles

| Documento | Rol |
|-----------|-----|
| **README.md** | Técnico: pipeline, cómo verificar |
| **MANIFIESTO.md** (este) | Qué sostiene el marco; enlace al ensayo |
| **docs/DEL_ORDEN_…** | Cómo se desarrolla la idea (canónico) |
| **EXPERIMENTOS.md** | Qué se mide y qué no |
| **docs/DELIMITACION_EPISTEMOLOGICA.md** | Qué cuenta como fundamento |

El manifiesto **funda**; el README **describe**. Un evaluador no necesita la
metafísica para ejecutar el núcleo ni el protocolo residual de encuentro.
