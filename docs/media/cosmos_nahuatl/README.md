# Medios — Cosmología náhuatl (Cinco Soles / Mictlán)

Recursos visuales y de referencia para el dominio de alineación `cosmos_nahuatl`.

| Archivo | Descripción | Uso en el marco I.O. |
|---------|-------------|----------------------|
| `Piedra_del_Sol.png` | Piedra del Sol (Calendario Azteca). Museo Nacional de Antropología. | Iconografía del **Quinto Sol** (Nahui Ollin) y las edades previas. Ancla visual de T01 / Totalidad–Evolución. |
| `4_Kingdoms.jpg` | Lámina de tradición codicial (cuatro reinos / deidades en bandas). | Dualidad y sucesión de fuerzas cosmológicas; apoyo a pares `mirrorOf` / `creates`. |

| `CodexBorgia.jpg` | Lámina del Códice Borgia (deidades, signos calendáricos). | Ritual y ciclo temporal mesoamericano; complemento visual a fases y edades. |
| `PECDSV03T.pdf` | Peña Cisneros, D. (2017). *Códice Xólotl. Edición de divulgación*. Tesis de Maestría en Producción Editorial, UAEM. | Referencia editorial e histórica del Códice Xólotl (tradición chichimeca; lectura de pinturas). Fuente de apoyo, no núcleo canónico. |

## Nota metodológica

Estos archivos son **material de apoyo semántico** para EXP-E y `docs/DOMINIO_COSMOS_NAHUATL.md`. No modifican los 78 nodos, Lean ni SHACL. La alineación formal sigue en `datasets/ingestion/templates/cosmos_nahuatl.csv`.
