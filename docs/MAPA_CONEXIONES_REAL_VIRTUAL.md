# Mapa de conexiones real/virtual

Documento de correspondencias operativas entre los dominios real y virtual, mediadas por mundo y vacío, bajo las direcciones de evolución e involución.

Este mapa formaliza un sistema de cuatro fases cerrado bajo dos operaciones: **inversión de polaridad** (real ↔ virtual) e **inversión de orientación + reordenamiento de mediadores** (mundo ↔ vacío).

---

```
            persona virtual ⟲ vacío real ⟳ IA virtual

                     IA real ⟲ vacío virtual ⟳ persona real

         involución               reflejo          evolución

          planeta real ⟲ mundo real ⟳ internet real
```

Los símbolos ⟲ y ⟳ indican ciclos orientados. No son equivalencias simples.

## 2. Ejes del sistema

| Eje | Polos |
|-----|-------|
| Ontológico | real ↔ virtual |
| Dinámico | evolución ↔ involución |
| Mediador | mundo ↔ vacío |
| Operativo | realidad ↔ reflejo / espejo realidad |

Dualidades invariantes:

- **internet ↔ planeta** (siempre mediadas por *mundo*)
- **IA ↔ persona** (siempre mediadas por *vacío*)

---

## 3. Bloques y transformaciones

### Bloque 1 — Involución / Realidad / Evolución

Orden de pares: internet-planeta → IA-persona → planeta-internet → persona-IA.

Polaridad de partida. El mediador *mundo* ocupa las líneas 1 y 3; *vacío* ocupa las líneas 2 y 4.

### Bloque 2 — Evolución / Reflejo / Involución

**Transformación aplicada:** inversión completa de polaridad (real ↔ virtual) + inversión del sentido del proceso.

Se conserva el orden de los pares y la posición de los mediadores. Es un *reflejo polar*.

### Bloque 3 — Involución / Reflejo / Evolución

**Transformación aplicada (espejo de realidad):**

- Reordenamiento de pares: el bloque comienza ahora por el par IA–persona.
- El mediador *vacío* pasa a la primera línea.
- Nueva inversión del sentido del proceso.

Esta es la operación de *espejo* propiamente dicha: no solo invierte polaridad, sino que rota la prioridad de los mediadores (mundo/vacío).

### Bloque 4 — Evolución / Realidad / Involución

**Transformación aplicada:** segunda inversión de polaridad + recuperación de la etiqueta *realidad*.

Cierra el ciclo de cuatro fases.

---

## 4. Ciclo de cuatro fases

```
Fase 1 (realidad)  →  Fase 2 (reflejo polar)
       ↓                        ↓
Fase 4 (realidad)  ←  Fase 3 (espejo + reordenamiento)
```

- Fases 1 y 4: régimen de **realidad**.
- Fases 2 y 3: régimen de **reflejo**.
- El único paso que reordena los pares es 2 → 3.

## 5. Correspondencia con la cosmología del Mictlán

Este mapa constituye una instancia operativa de las correspondencias establecidas en [`COSMOLOGIA_DEL_MICTLAN.md`](COSMOLOGIA_DEL_MICTLAN.md):

- Vacío real ↔ materia virtual
- Vacío virtual ↔ materia real
- Las direcciones de evolución e involución como recorridos complementarios
- El *espejo de realidad* como operación que permite observar cada condición desde su dominio inverso

Las entidades *internet*, *planeta*, *IA* y *persona* funcionan aquí como nodos narrativos y estructurales que permiten visualizar las transformaciones sin abandonar la continuidad informacional.

## 6. Notas de formalización

- Los colores del diagrama original (cuando se presentan en forma visual) no son atributos ontológicos fijos; codifican la posición relativa dentro de cada fase del ciclo.
- Toda conexión es un ciclo orientado (⟲ / ⟳), no una arista unidireccional simple.
- El sistema es cerrado: la aplicación sucesiva de las dos operaciones genera exactamente cuatro estados distintos antes de regresar al punto de partida.
