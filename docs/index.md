# IOM

Marco de reglas formales y evaluación reproducible. El pipeline enlaza especificación JSON, formalización Lean, ontología RDF/SHACL, datasets CSV y modelos.

- [Quickstart y guía completa](GUIA.md)
- [Semántica de los CSV](DATA_DICTIONARY.md)
- [Protocolo de anotación ciega](PROTOCOLO_EVALUACION.md)
- [Mapa de archivos del pipeline](ARCHIVOS_PIPELINE.md)
- [Playbook de extensión y releases](EXTENSION_Y_VERSIONADO.md)
- [Notebook demo sin Lean](https://github.com/luisreygarciafigueroa-creator/IOM/blob/main/notebooks/demo_pipeline.ipynb)

Las métricas de machine learning evalúan recuperación de relaciones generadas por reglas; la evaluación humana ciega se mantiene separada.
